# Visual assets

The custom hero is included at `public/images/hero.webp`. It was created with the built-in imagegen tool for this project and optimized to WebP. The original is retained in the working session's generated images.

Final prompt:

> Use case: product-mockup. Asset type: wide hero photo for a polished Nigerian e-commerce website called Kora. Primary request: an editorial studio still-life of thoughtfully curated everyday products, a pair of modern cream over-ear headphones resting against stacked beige travertine blocks, a tan leather structured small handbag, a minimal amber skincare bottle and a small matte terracotta ceramic vase. Scene/backdrop: warm ivory and oat-beige seamless studio background, sculptural blocks, warm afternoon window-light shadows. Composition/framing: panoramic 3:2, objects grouped on the right half with generous completely empty ivory negative space on left for website headline. Headphones are largest and center-right with bag behind, carefully balanced. Style: photoreal high-end product photography, tactile and understated, fine natural grain. Color palette: cream, sand, caramel, muted olive. Constraints: no text, no lettering, no logos, no watermarks, no people. This is an image asset only, not a webpage screenshot.
